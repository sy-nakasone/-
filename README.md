# 📝 AI会議議事録自動生成アプリ

**Webアプリから音声をアップロードするだけ。部署管理・利用履歴付き。**

## ✨ 特徴

| 機能 | 説明 |
|------|------|
| 📤 **Webアプリ** | ブラウザからファイルをアップロード |
| 🏢 **部署管理** | どの部署が利用したか記録 |
| 📁 **フォルダ連携** | Googleドライブのフォルダを選択式で指定 |
| 📊 **利用履歴** | 誰がいつ利用したか確認可能 |
| 📈 **統計ダッシュボード** | 部署別利用頻度をグラフで可視化 |
| ⚙️ **簡単管理** | スプレッドシートで部署・フォルダを編集 |
| 🤖 **Gemini AI** | 高精度な日本語音声認識・要約 |

## 🚀 セットアップ（約20分）

### 1. 管理用スプレッドシートを作成

以下の3つのシートを作成:

| シート名 | 内容 |
|---------|------|
| `部署マスタ` | 部署ID、部署名 |
| `フォルダマスタ` | フォルダID、フォルダ名、GoogleドライブフォルダID |
| `利用履歴` | 自動記録（ヘッダーのみ作成） |

### 2. Gemini APIキーを取得

[Google AI Studio](https://aistudio.google.com/apikey) から無料で取得

### 3. デプロイ

```bash
cd app
chmod +x deploy.sh
./deploy.sh
```

### 4. 権限設定

サービスアカウントをスプレッドシートとGoogleドライブフォルダに共有

**詳細は [SETUP_GUIDE.md](./SETUP_GUIDE.md) を参照**

## 📊 管理用スプレッドシート

**ノンプログラマーでも編集可能！**

### 部署マスタ

| ID | 部署名 |
|----|--------|
| sales | 営業部 |
| dev | 開発部 |
| hr | 人事部 |

### フォルダマスタ

| ID | フォルダ名 | GoogleドライブフォルダID |
|----|-----------|-------------------------|
| regular | 定例会議 | 1ABC...XYZ |
| project_a | プロジェクトA | 1DEF...XYZ |

### 利用履歴（自動記録）

| 日時 | 部署 | フォルダ | ファイル名 | ステータス | 議事録URL |
|------|------|---------|-----------|-----------|----------|
| 2026-01-06 10:30 | 営業部 | 定例会議 | meeting.mp3 | 完了 | https://... |
