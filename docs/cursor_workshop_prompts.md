# Cursor研修用：実践プロンプト集（コピペ用）

ノンプログラマーの方がCursorの威力を体感できる、実践的なプロンプト（指示文）の例です。
研修のワークショップでそのままコピー＆ペーストして使用してください。

---

## 演習1：簡単なWebツールの作成
**目的**: 「言葉だけでアプリが作れる」体験をする。

**プロンプト**:
```text
TODOリスト管理アプリを作ってください。
以下の機能を入れてください。
1. タスクの追加と削除ができる
2. タスクに「未完了」「完了」のチェックボックスをつける
3. デザインはシンプルで、色は水色を基調にしてください
4. HTML、CSS、JavaScriptを1つのファイル（index.html）にまとめて書いてください
```

---

## 演習2：Excel・スプレッドシートの数式作成
**目的**: 普段の業務（表計算）のアシスタントとして使う。

**プロンプト**:
```text
私はExcelで顧客リストを管理しています。
A列に「2023/10/01」のような日付が入っています。
B列に、その日付が「土曜日」か「日曜日」の場合だけ「休日」、それ以外なら「平日」と表示させる関数を教えてください。
また、祝日も考慮する方法があれば教えてください。
```

---

## 演習3：文章の校正・要約
**目的**: ビジネス文書の作成補助として使う。

**プロンプト**:
```text
以下の文章は、取引先に送る謝罪メールの下書きです。
もっとビジネスとして適切な、丁寧な表現に書き換えてください。
また、言い訳がましく聞こえる部分は修正してください。

【下書き】
お世話になります。
昨日送った資料ですが、数字が間違っていました。すみません。
忙しくて確認を忘れていました。
正しいやつを添付するので見てください。
よろしくお願いします。
```

---

## 演習4：データ分析（Python入門）
**目的**: 「プログラミングでデータ分析」を体験する（少し発展的）。
※この演習はCursor上でPythonファイル(.py)を作成する流れになります。

**プロンプト**:
```text
Pythonを使って、ダミーの売上データを作ってください。
1. 日付、商品名、単価、個数、売上合計 の列を持つCSVデータを作りたいです。
2. データは100行分ランダムに生成してください。
3. そのデータを「sales.csv」という名前で保存するコードを書いてください。
```
