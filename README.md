## 📚 各ファイルの説明

### 1. Cursor_AI_研修マニュアル.md
**対象**: 研修受講者（ノンプログラマー）

主な内容:
- Cursor AIの概要
- インストール方法
- 画面構成の説明
- 基本操作
- AIチャットの使い方
- 効果的なプロンプトの書き方
- 実践演習
- ショートカットキー一覧
- FAQ・トラブルシューティング
- 用語集

### 2. Cursor_AI_研修_講師ガイド.md
**対象**: 研修講師・運営者

主な内容:
- 研修の準備チェックリスト
- タイムスケジュール（3時間版）
- 各セクションの進め方
- よくある質問への対応
- トラブル対応
- フォローアップ方法

### 3. Cursor_AI_クイックリファレンス.md
**対象**: 研修受講者（日常使用時）

主な内容:
- よく使うショートカット

※ 印刷してデスクに貼っておくと便利です

### 4. 演習用サンプルファイル/
**対象**: 研修受講者（演習時）

実際に手を動かして学ぶための演習ファイル:
- 演習1: ビジネスメールの作成
- 演習2: 会議メモから議事録作成

- 演習4: 文章の校正
- 演習5: 比較表の作成

## 🚀 使い方

### 研修受講者の方
1. `Cursor_AI_研修マニュアル.md` を開いて学習
2. `演習用サンプルファイル/` 内の課題に取り組む
3. `Cursor_AI_クイックリファレンス.md` を印刷して手元に

### 講師・運営者の方
1. `Cursor_AI_研修_講師ガイド.md` で進行方法を確認
2. 事前準備チェックリストを実施
3. タイムスケジュールに沿って研修を実施
